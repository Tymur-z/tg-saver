# tg-saver — Telegram Media Forwarder, AI Stylometry & Moderation Bot

[![Python 3.12](https://img.shields.io/badge/python-3.12-blue.svg)](https://www.python.org/)
[![aiogram 3](https://img.shields.io/badge/aiogram-3.x-green.svg)](https://docs.aiogram.dev/)
[![SQLite](https://img.shields.io/badge/sqlite-3-lightgrey.svg)](https://www.sqlite.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Многофункциональный асинхронный Telegram-бот на Python (**aiogram 3**), объединяющий гибкую маршрутизацию контента, двухуровневую систему модерации ненормативной лексики с поддержкой ИИ, управление параметрами нейросетей прямо из Telegram-интерфейса и стилометрический анализ речи участников.

---

## 🚀 Ключевые возможности

### 1. 🔀 Продвинутая пересылка сообщений (Forwarding Engine)
- **Режимы доставки:** 
  - `Forward` — нативная пересылка со ссылкой на автора/источник.
  - `Copy` — чистая копия сообщения без авторства.
- **Сборка медиагрупп (Альбомов):** корректный сбор и объединение фото/видео с общим `media_group_id` через настраиваемое debounce-окно.
- **Фильтрация контента:**
  - По типам медиа (текст, фото, видео, видео-кружочки, голосовые, стикеры, файлы, аудио, GIF).
  - По ключевым словам (включение) и стоп-словам (исключение).
  - Очистка текста: удаление внешних гиперссылок, хештегов и `@упоминаний`.
- **Защита от циклов и дублирования:**
  - Алгоритм DFS на этапе конфигурации исключает создание циклических маршрутов (`A → B → C → A`).
  - Двухфазная регистрация в базе данных гарантирует идемпотентность и исключает повторную пересылку при сбоях сети.
- **Rate Limiting & Backoff:** асинхронная очередь отправки с соблюдением лимитов Telegram API (до 20–30 сообщений/мин на чат) и автоматическим ожиданием при получении `Retry-After`.

---

### 2. 🛡️ Модерация ненормативной лексики (Hybrid AI Moderation)
- **Двухуровневый анализ (Hybrid Engine):**
  - **Tier 1 (Instant Regex Pre-filter):** мгновенная локальная проверка (0 мс, 0$ затрат) с авто-нормализацией leetspeak (`п1зд@`, `еб@ть`, повторы букв) и проверкой по белому списку разрешенных слов (`рубль`, `страхование`, `колебания`, `хлеб` и др.).
  - **Tier 2 (Deep Contextual LLM):** глубокий анализ через нейросеть при включении тумблера ИИ для распознавания замаскированных оскорблений и скрытого мата.
- **Индивидуальная настройка по каждому чату:**
  - `[🛡️ Фильтр матов]` — включение/отключение модерации в конкретной группе/канале.
  - `[⚠️ Предупреждать нарушителя]` — отправка персонального предупреждения нарушителю с упоминанием в чате.
  - `[🗑️ Удалять сообщение]` — автоматическое удаление нецензурного сообщения (при наличии прав администратора у бота).
- **Режим тишины в группах:** бот не реагирует на команды участников в групповых чатах, вся настройка доступна только администраторам через личные сообщения.

---

### 3. 🤖 Управление ИИ прямо из Telegram-бота (No-Code LLM Setup)
Больше не нужно редактировать файлы на сервере или перезапускать бота для смены ключа или модели. Все параметры настраиваются в меню `/llm`:
- **API-ключ:** ввод ключа прямо через чат бота (сообщение с секретным ключом сразу удаляется из истории для безопасности).
- **Выбор модели:**
  - Быстрые пресеты: `gpt-4o-mini`, `gemini-1.5-flash`, `gpt-4o`, `gemini-1.5-pro`, `deepseek-chat`.
  - Возможность ручного ввода любой совместимой модели.
- **Эндпоинт (Base URL / IP-адрес):**
  - Официальный OpenAI API (`https://api.openai.com/v1`).
  - Google Gemini OpenAI-compatible эндпоинт (`https://generativelanguage.googleapis.com/v1beta/openai/`).
  - Произвольный IP/URL вашего сервера с vLLM, Ollama или LocalAI (например, `http://192.168.1.50:11434/v1`).
- **Тестирование соединения (Ping):** проверка связи с нейросетью в реальном времени с измерением задержки отклика в миллисекундах (`latency_ms`).

---

### 4. 📊 Стилометрический анализ (Communication Style Profiler)
- **Концепция Zero-Raw-Text:** исходные тексты сообщений не сохраняются в базе данных — рассчитываются только числовые коэффициенты стиля.
- **Анализируемые метрики:**
  - Средняя и медианная длина сообщений и предложений.
  - Лексическое разнообразие (Type-Token Ratio, TTR).
  - Частотность знаков препинания, скобок и эмодзи.
  - Маркеры формальности, приветствий и сленга.
  - Активность по часам суток.
- **Мимикрия стиля:** автоматическая генерация системных промптов для языковых моделей, позволяющих ИИ генерировать ответы в тональности автора.
- **Сравнение текстов:** команда `/compare` сопоставляет произвольный фрагмент текста с личным стилометрическим профилем.

---

### 5. 🔒 Безопасность и авторизация (RBAC)
- **Роли пользователей:** `owner`, `admin`, `user`, `guest`.
- **Защита паролем:** возможность обязательной авторизации новых пользователей по паролю (`/password`).
- **Изоляция данных:** обычные пользователи видят и настраивают только свои маршруты и профиль стиля; администраторам доступны глобальные списки всех маршрутов и управление аккаунтами (`/users`).

## 🛠️ Быстрый старт

### 1. Клонирование репозитория и виртуальное окружение

```bash
git clone https://github.com/Tymur-z/tg-saver.git
cd tg-saver

python -m venv venv

# Windows
.\venv\Scripts\activate

# Linux / macOS
source venv/bin/activate

pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Скопируйте пример конфигурационного файла:

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```ini
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
OWNER_ID=911338473
DATABASE_PATH=data/forwarder.db
ACCESS_PASSWORD=7788
PASSWORD_REQUIRED=true
```

*(Настройки LLM можно оставить по умолчанию и настроить их позже прямо в боте через команду `/llm`).*

### 3. Запуск бота

```bash
python main.py
```

## ⚙️ Переменные окружения (.env)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | *обязательный* | Токен бота от BotFather |
| `OWNER_ID` | `0` | Числовой ID супер-администратора (из @userinfobot) |
| `ADMIN_IDS` | `""` | Дополнительные ID администраторов через запятую |
| `DATABASE_PATH` | `data/forwarder.db` | Путь к базе данных SQLite |
| `LOG_LEVEL` | `INFO` | Уровень логирования (`DEBUG`, `INFO`, `WARNING`, `ERROR`) |
| `FORWARD_RATE_LIMIT_PER_MINUTE` | `20` | Максимальное число пересылаемых сообщений в минуту на чат |
| `QUEUE_MAX_SIZE` | `500` | Максимальный размер асинхронной очереди |
| `ALBUM_DEBOUNCE_SECONDS` | `0.8` | Окно ожидания всех элементов альбома (сек) |
| `ACCESS_PASSWORD` | `7788` | Пароль доступа по умолчанию для новых пользователей |
| `PASSWORD_REQUIRED` | `true` | Требовать ли пароль при первом входе |
| `ANALYTICS_ENABLED` | `true` | Включение модуля стилометрии |
| `LLM_ENABLED` | `false` | Использовать ли внешнюю LLM по умолчанию |
| `LLM_BASE_URL` | `https://api.openai.com/v1` | URL API поставщика нейросети |
| `LLM_MODEL` | `gpt-4o-mini` | Название модели по умолчанию |

## 🤖 Команды Telegram-бота

### Пользовательские команды
- `/start` — главное интерактивное меню и проверка пароля.
- `/routes` — мои персональные маршруты пересылки.
- `/sources` — список доступных чатов-источников.
- `/destinations` — список целевых каналов и групп.
- `/profile` — лингвистический портрет и статистика стиля.
- `/compare <текст>` — сравнение текста со своим стилем.
- `/mimic` — генерация промпта для ИИ для имитации стиля.
- `/privacy` — настройки приватности и удаление персональных данных.

### Команды администратора
- `/admin` — главная админ-панель управления.
- `/moderation` — управление фильтрами матов и предупреждениями по группам и каналам.
- `/llm` — настройка ИИ: ввод API-ключа, выбор модели, IP/URL эндпоинта и тест связи.
- `/users` — управление пользователями (блокировка, назначение админов, сброс паролей).
- `/password` — смена пароля доступа и переключение требования пароля.
- `/all_routes` — просмотр всех маршрутов всех пользователей в системе.
- `/all_chats` — просмотр всех каналов и групп, где присутствует бот.
- `/status` — состояние очередей, пауза и статистика доставки.
- `/pause` / `/resume` — глобальная приостановка / возобновление пересылки.

## 🐧 Развертывание на Linux VPS (Systemd)

Создайте файл службы `/etc/systemd/system/tg-forwarder.service`:

```ini
[Unit]
Description=Telegram Media Forwarder & Stylometry Bot
After=network.target

[Service]
Type=simple
User=ec2-user
WorkingDirectory=/home/ec2-user/tg-forwarder
ExecStart=/home/ec2-user/tg-forwarder/venv/bin/python main.py
Restart=always
RestartSec=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

Активация и запуск:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now tg-forwarder
sudo systemctl status tg-forwarder
```
