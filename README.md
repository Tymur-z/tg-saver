# tg-saver

Асинхронный Telegram-бот на Python (aiogram 3) для пересылки сообщений между чатами, каналами и группами, фильтрации мата и анализа стиля общения.

---

## Возможности

### Пересылка сообщений
- **Режимы доставки:**
  - `Forward` — пересылка со ссылкой на автора и источник.
  - `Copy` — чистая копия сообщения без авторства.
- **Поддержка медиагрупп (альбомов):** сборка фото и видео в один альбом перед отправкой.
- **Фильтрация контента:**
  - По типам медиа (текст, фото, видео, кружочки, голосовые, стикеры, файлы, аудио, GIF).
  - По ключевым словам и стоп-словам.
  - Удаление внешних ссылок, хештегов и @упоминаний.
- **Защита от дублей и петель:** проверка графа маршрутов на зацикливание и регистрация отправленных сообщений в SQLite.
- **Очередь сообщений:** соблюдение лимитов Telegram API и автоматический backoff при `Retry-After`.

### Модерация ненормативной лексики
- **Быстрый regex-фильтр:** проверка частых матерных корней, учет замен символов и белый список исключений.
- **Проверка через LLM:** опциональный глубокий анализ для выявления скрытого мата и оскорблений.
- **Действия по чатам:** раздельное включение фильтра, автоудаления сообщений и предупреждений нарушителям.
- **Режим тишины:** в группах бот не реагирует на команды обычных участников; все настройки производятся в ЛС администратора.

### ИИ-собеседник (Режим общения)
- **Контекстный диалог:** бот хранит скользящий буфер недавних сообщений чата и может кратко ввести в курс дела («о чем тут говорили?», «что обсуждали?»), поддержать непринужденный разговор или подбодрить участников во время учебы или работы.
- **Активация:** в группах бот отвечает только при теге (`@username`) или ответе (Reply) на его сообщение, не спамя в остальное время.
- **Индивидуальное управление:** режим общения включается и выключается для каждого конкретного чата в меню `/moderation`.

### Настройка LLM из Telegram
Параметры нейросети можно настроить прямо в диалоге с ботом (команда `/llm`):
- Установка и смена API-ключа (сообщение с ключом удаляется сразу после сохранения).
- Выбор модели (OpenAI `gpt-4o-mini`, `gpt-4o`, Google `gemini-1.5-flash`, `deepseek-chat` или ввод своей).
- Выбор эндпоинта (OpenAI, Gemini OpenAI-endpoint или локальный адрес vLLM/Ollama).
- Проверка подключения (`Ping`) с замером времени ответа.

### Анализ стиля сообщений
- Расчет метрик стиля (средняя длина сообщений, пунктуация, смайлы, маркеры сленга) без сохранения самих текстов.
- Команда `/compare` для сопоставления произвольного текста с профилем.
- Генерация системного промпта для имитации тональности автора.

### Доступ и безопасность
- Разграничение прав по ролям: Owner, Admin, User.
- Защита доступа по паролю (настраивается через `/password`).
- Пользователи управляют только своими маршрутами, администраторам доступен полный список.

## Установка и запуск

### 1. Клонирование и зависимости

```bash
git clone https://github.com/Tymur-z/tg-saver.git
cd tg-saver

python -m venv venv

# Windows
.\venv\Scripts\activate

# Linux / macOS
source venv/bin/activate

pip install -r requirements.txt
```

### 2. Настройка переменных окружения

```bash
cp .env.example .env
```

Заполните основные параметры в `.env`:

```ini
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
OWNER_ID=911338473
DATABASE_PATH=data/forwarder.db
ACCESS_PASSWORD=7788
PASSWORD_REQUIRED=true
```

### 3. Запуск

```bash
python main.py
```

## Переменные окружения (.env)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | *обязательный* | Токен бота от BotFather |
| `OWNER_ID` | `0` | Telegram ID владельца бота |
| `ADMIN_IDS` | `""` | Дополнительные ID администраторов через запятую |
| `DATABASE_PATH` | `data/forwarder.db` | Путь к базе SQLite |
| `LOG_LEVEL` | `INFO` | Уровень логов (`DEBUG`, `INFO`, `WARNING`, `ERROR`) |
| `FORWARD_RATE_LIMIT_PER_MINUTE` | `20` | Лимит сообщений в минуту на один чат |
| `QUEUE_MAX_SIZE` | `500` | Максимальный размер очереди отправки |
| `ALBUM_DEBOUNCE_SECONDS` | `0.8` | Окно ожидания медиагруппы (сек) |
| `ACCESS_PASSWORD` | `7788` | Пароль доступа для новых пользователей |
| `PASSWORD_REQUIRED` | `true` | Проверка пароля при входе |
| `ANALYTICS_ENABLED` | `true` | Включение модуля аналитики стиля |
| `LLM_ENABLED` | `false` | Включение проверки через LLM |
| `LLM_BASE_URL` | `https://api.openai.com/v1` | URL API эндпоинта |
| `LLM_MODEL` | `gpt-4o-mini` | Название модели |

## Команды бота

### Основные
- `/start` — главное меню и авторизация
- `/routes` — управление маршрутами пересылки
- `/sources` — список подключенных источников
- `/destinations` — список чатов-назначений
- `/profile` — статистика стиля общения
- `/compare <текст>` — сравнение текста с профилем стиля
- `/mimic` — генерация промпта в тональности автора
- `/privacy` — настройки приватности и удаление данных

### Административные
- `/admin` — панель управления
- `/moderation` — настройка фильтра матов, предупреждений и ИИ-общения по чатам
- `/llm` — настройка модели, API-ключа и адреса эндпоинта
- `/users` — список и управление пользователями
- `/password` — смена пароля доступа
- `/all_routes` — просмотр всех маршрутов в системе
- `/all_chats` — все чаты бота
- `/status` — состояние очередей и статистика
- `/pause` / `/resume` — пауза и возобновление пересылки

## Развертывание (Systemd)

Файл `/etc/systemd/system/tg-forwarder.service`:

```ini
[Unit]
Description=Telegram Media Forwarder Bot
After=network.target

[Service]
Type=simple
User=ec2-user
WorkingDirectory=/home/ec2-user/tg-forwarder
ExecStart=/home/ec2-user/tg-forwarder/venv/bin/python main.py
Restart=always
RestartSec=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now tg-forwarder
```
